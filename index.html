Admin Password
Set or update a password for your admin account () so "Admin sign in" works as a backup alongside Google Sign-In. If you've never set one (or aren't sure), just set one here now.
Data Backup
Download a full snapshot of everything in the app (snags, service action reports, projects, tasks, staff list, settings) as one JSON file. It doesn't restore automatically — keep it somewhere safe (your computer, Google Drive) so you have something to rebuild from if data is ever lost.
Restoring writes data from a backup file back into the live database. It adds back anything the file contains (overwriting the current version of any document with the same ID) — it does not delete anything that already exists but isn't in the file. Use this to recover lost items, not to fully reset the app to an old state.
